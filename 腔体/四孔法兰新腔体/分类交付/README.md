# 时钟模块腔体分类交付

- **01_加工文件_仅底座与盖板.zip**：仅底座和盖板，各含 SolidWorks 原生零件及 STEP，共4个文件。
- **02_完整装配.zip**：包含32组件完整三维装配、全部引用零件、装配 STEP、预览及核验记录。解压后打开“完整装配/装配体/时钟模块腔体装配.SLDASM”，请保持引用目录结构。

针脚间隙实测约0.247 mm，Type-C下方槽深1 mm。装配组件均浮动，以保存位置定位，未添加配合。源模型存在的Type-C相关重叠详见装配包中的核验记录。

加工件只有底座和盖板，其余零件用于装配参考。文件SHA-256见“文件校验.json”。
